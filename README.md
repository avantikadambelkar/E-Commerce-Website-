# ✦ AURA LUXE — Contemporary Luxury E-Commerce & Shopping App

Built with **Python 3.14**, **Django 6.1**, **SQL (Django ORM)**, **HTML5**, **Bootstrap 5.3**, and **Custom Glassmorphism CSS**.

Designed with Indian Rupee (₹ / INR) pricing, Indian payment methods, and a dedicated Catalog CRUD Management Dashboard.

## 🌟 Key Features

- **Distinct Aesthetic Design:** Editorial dark glassmorphism, warm gold accents, and modern typography.
- **Shopping App Experience:** Story category bubbles, sticky mobile bottom navigation, and AJAX cart and wishlist updates.
- **Indian Rupee Pricing:** Product prices, GST breakdown, and shipping thresholds in INR.
- **Product Management:** Create, Read, Update, and Delete products.
- **Cart:** Dynamic quantity updates, item removal, and promotional coupons.
- **Wishlist:** One-click wishlist management.
- **Reviews:** Star ratings and customer feedback.
- **Checkout & Orders:** Shipping address form and order tracking.

## 🚀 Quick Start

```bash
# Apply database migrations
python manage.py migrate

# Seed catalog data
python manage.py seed_data

# Run tests
python manage.py test

# Start development server
python manage.py runserver
```
